Deployment Harness for Robotics

We take robots from the lab to the production line.

Robot models are improving fast, but no single model, vendor or release runs a whole site. Core Labs builds the deployment harness between a site’s work and the models that drive its robots, so every task runs on the right model, inside the site’s rules, with a record of every decision.

Route

Send each task to the model with the best measured record on it.

Enforce

Check every action against the site’s rules before the robot moves.

Comply

A signed trail of which model ran, what it proposed and what was allowed.

Recover

Turn every failure into a rule the whole fleet inherits.

Benchmarks

Routing beats the best single model on standard benchmarks.

We applied task-level routing to the published per-task results of three widely used robot benchmarks. On each one, sending every task to its best model outscores the strongest individual model.

Each square is one benchmark task. Blue squares are tasks where a model other than the best overall one wins, which is where routing earns its gain.

How the router decides

Measured, not claimed.

  1. 1
    Match the taskCompare each work order with what every model has been trained and tested on: scenes, objects and skills.
  2. 2
    Read the recordPull each model’s measured success on this task, on this robot, at this site.
  3. 3
    Decide with confidenceSwitch models only when the lead is statistically real. If no model is confident, hand the task to a human operator.
